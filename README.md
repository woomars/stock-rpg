# 목숨걸고 투자

실제 과거 주가 구간 위에서 사고팔아 기업 몬스터를 쓰러뜨리는 1인칭 모바일 웹게임입니다. 계좌가 곧 목숨입니다. 죽으면 내공이 쌓이고, 영구 강화로 조금씩 강해져 Clear에 도전합니다.

**플레이:** https://woomars.github.io/stock-rpg/

저장, 투자 기록, 내공은 쓰고 있는 브라우저에만 남습니다. 여정 화면에서 백업 파일로 내보낼 수 있습니다.

개인 재미를 위한 비상업 프로젝트이며 투자 조언이 아닙니다. 시세는 Yahoo Finance와 네이버 금융에서 받았고, 데이터의 권리는 각 제공처에 있습니다. 기업 로고의 권리는 각 회사에 있습니다.
